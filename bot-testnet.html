🚀 Démarrage simplifié sur Windows

1. Télécharger HyperBot (ZIP) puis extraire le dossier.

2. Double-cliquer sur bot/START_TESTNET_WINDOWS.bat. Le lanceur installe les dépendances et ouvre le fichier de configuration privée lors du premier lancement.

3. Renseigner l'adresse publique de votre compte et une clé API Wallet Testnet dédiée, obtenue depuis le site officiel. Ne jamais utiliser votre clé principale.

4. Relancer le fichier .bat : choisir 1 pour vérifier sans ordre, ou 2 pour préparer un seul ordre d'achat Testnet après confirmation.

Le bot n'est pas encore un moteur GRID achat/vente autonome. Aucun ordre n'est envoyé depuis ce navigateur ; la fenêtre Windows doit rester ouverte pour exécuter le script. Les données publiques Testnet peuvent être indisponibles.

Essayer un ordre de test

Le moteur Python du dépôt est configuré pour le Testnet. Il démarre en lecture seule et exige une confirmation locale avant d'envoyer un unique achat limite de test.

Ouvrir les fichiers et le guide d'installation du moteur

pip install -r bot/requirements.txt
python bot/grid_bot.py
# Après configuration de la clé API Wallet TESTNET et vérification :
python bot/grid_bot.py --execute
